# ResumeIQ

AI-powered resume analyzer built with the MERN stack and Google Generative AI (Gemini).

## Structure
- `client/` - React frontend (Vite, Tailwind CSS)
- `server/` - Node.js + Express API

## Getting Started

1. Clone the repository
2. Run `npm install` in the root directory to install concurrently
3. Run `cd client && npm install` to install frontend dependencies
4. Run `cd server && npm install` to install backend dependencies
5. Set up your `.env` file in the `server` directory (see `server/.env.example`)
6. Run `npm run dev` from the root directory to start both client and server simultaneously.
